If you landed on the homepage, you probably noticed it said something
suspiciously specific to you: the time of day, your browser, maybe a jab about
how you got here. Here's how that works, and why it doesn't cost a single
server request or store anything about you.

## The whole trick is the browser already knows

Every browser hands a page a surprising amount of context for free, with no
permission prompt and no network call:

- **Local time** via `new Date()`, enough for "good evening" or a 3 a.m. joke.
- **Timezone** via `Intl.DateTimeFormat().resolvedOptions().timeZone`.
- **Device, OS, and browser**, parsed from the user-agent string.
- **The referrer** via `document.referrer`: did you arrive from Google, Hacker
  News, or type the URL directly?
- **Dark-mode preference** via `matchMedia('(prefers-color-scheme: dark)')`.

None of this identifies you. It's ambient context, the same context every site
silently uses for analytics. The difference here is that I use it to say hello
and then immediately forget it.

## Read signals, write a sentence

The implementation is two small functions. One reads the signals:

```ts
export function readSignals() {
  const now = new Date();
  const ua = navigator.userAgent;
  return {
    hour: now.getHours(),
    timezone: Intl.DateTimeFormat().resolvedOptions().timeZone,
    browser: detectBrowser(ua),
    referrer: classifyReferrer(document.referrer),
  };
}
```

The other turns those signals into one witty line by picking an opener for the
time of day and an applicable "jab" for the browser or referrer. Because it
picks randomly among the lines that apply, a reload often gives you a fresh one.

## Keeping it SEO-safe

There's one catch with personalization on a static site: the server has no idea
what time it is for *you*, so it can't render the personalized line at build
time. If you tried, you'd get a hydration mismatch.

The fix is to render a neutral fallback line in the static HTML and swap in the
personalized one inside a `useEffect`, after the component mounts in the
browser. Crawlers and no-JS visitors see a perfectly sensible hero; everyone
else gets the personal touch a few milliseconds later.

> Progressive enhancement, but for charm.

That's the entire feature. No database, no cookies sent to a server, no privacy
policy required, just a friendlier first impression.
