# Press kit — asset manifest

Everything the campaign can hand to a juror, a journalist, or a "Made with"
feature request, and where it lives. Two storage tiers:

- **Committed** — small, load-bearing assets that ship with the site or the
  docs. Stable paths, versioned with the code.
- **Regenerated per release** — large capture artifacts. They live in
  `scratchpad/submission/` (gitignored) between runs and are archived with
  the judged build (docs/RUNBOOK.md → "Judged-build archive"); only their
  manifest is committed.

## Regeneration procedure (release step)

```sh
pnpm build
node scripts/gen-og-cards.mjs && node scripts/optimize-public-images.mjs && pnpm build   # commit public/og/
node scripts/shoot-submission.mjs                                                        # commit the manifest
node scripts/record-reel.mjs
node scripts/shoot-routes-grayscale.mjs
```

Run captures on real GPU hardware for submission-grade pixels — sandbox/CI
boxes render through SwiftShader (slow, and bloom/grade fidelity differs).
